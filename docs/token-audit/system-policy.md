# 디자인시스템 단일 기준 적용

이 문서는 이전 `README.md`의 화면 보존 정책을 대체합니다. 이번 요청에 따라 기준 밖 값을 그대로 두지 않고 현재 디자인시스템 척도로 정규화했습니다.

- 원본: `public/assets/js/design-system-foundations.js`
- 생성 CSS: `public/assets/css/tokens.css` (`npm run build:tokens`)
- 디자인시스템 페이지도 같은 원본의 간격·타이포·모서리·그림자 정의를 읽습니다.
- 관리 토큰 128개. 런타임 `--qm-*` 참조 0개. CSS 클래스 이름은 토큰 이름과 별개로 유지합니다.
- 간격은 문서의 4/8/12/16/20/24/32/40/48/56/64/80px. `gap:9px` → `gap:var(--space-8)`, 25/26px 여백 → 24px, 45px 여백 → 48px.
- 10px 글자 → Caption 2의 11px, 23px 제목 → Title 3의 24px 등 문서의 타이포 크기·행간·자간과 400/500/600/700 굵기를 사용합니다.
- 문서 밖의 보조 배경·테두리·그림자·900ms/200ms 모션·28/36px 간격 토큰은 제거하고 문서의 의미별 색상·3단계 그림자·동작 시간으로 연결했습니다.
- 원형 모양의 50%, 레이아웃의 %, fr, 미디어 조건, 이미지·컨테이너 구조 치수는 구조 규칙입니다. 이를 새 전역 수치 토큰으로 만들지 않았습니다. 화면에서 숨기는 보조기기 전용 요소의 -1px 규칙도 유지합니다.
- 흰색 프라이머리 텍스트와 포커스 외곽선 제거 설정은 유지했습니다.

`npm run check:styles`는 생성 CSS 일치, 접두사 잔존, 미정의 참조, 순환, 중복 선언, CSS의 직접 입력 간격, JS 모듈 경로를 검사합니다. 디자인 변경은 원본을 수정하고 `npm run build:tokens`를 실행합니다.

검증: 기능 테스트 15개 통과. 1440/390px에서 주요 페이지와 디자인시스템 22개 조건이 실제 렌더링되었고 콘솔/런타임 오류 및 가로 넘침은 0개입니다. 기준 척도로 통일했으므로 이전 화면과 간격·글자·보조 색상에는 의도적인 차이가 있습니다. 캡처는 로컬 `system-after/`에 저장했습니다.

이전의 `before.json`, `after.json`, `inventory.md`, `audit.py`, `compare.py`는 앞선 보존 작업의 기록입니다. 현재 기준 검증은 `npm run check:styles`를 사용합니다.
