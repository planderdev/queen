# 정보구조

공개 영역: 홈 → 기부하기(분야/지역/단체/상태/정렬/검색) → 모금 상세(이야기/참여내역/소식·결과보고/댓글) → 기부 3단계 → 완료.

지속 참여: 정기기부 소개 → 단체 프로그램 → 월 금액/일자 → 약정 확인 → 마이페이지 관리.

브랜드·신뢰: 캠페인 목록/상세, 스토리 목록/상세, 단체 목록/상세, 소개, 고객센터(FAQ/공지/문의/이용·개인정보 안내).

회원: 데모 로그인/가입/재설정 안내 → 나의 요약/거래/정기/관심/캠페인/댓글/알림/프로필/문의.

단체: 대시보드/신청/프로필/내 모금/작성/소식/지급/결과보고/문의·알림.

기업: 대시보드/프로필/캠페인 제안/성과/지원금/문의.

관리자: 대시보드/회원/단체심사/모금심사·게시/거래/정기/환불/지급/보고심사/기업/콘텐츠/신고/문의/설정/권한/이력.

모든 운영 영역은 같은 토큰을 사용하는 독립 사이드바 레이아웃이다. 모바일 사이드바는 수평 스크롤 메뉴, 표는 컨테이너 내부 스크롤로 제공한다.
