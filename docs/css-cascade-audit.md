## 검증

11개 페이지를 1440px·390px에서 확인. 화면에 표시되는 DOM 요소의 크기·간격·폰트·색·테두리·레이아웃 등 25개 computed-style 속성을 비교했다. 셀렉트 간격과 이야기 카드의 반응형 순서 차이를 수정한 뒤 비교 대상 속성의 차이는 0개였다. 애니메이션 중간 프레임, 모든 hover 상태 및 모든 중간 해상도의 픽셀 일치를 보증하는 검사는 아니다.

메인페이지의 title/slide 함수에 heading 인자가 누락된 별도 렌더링 오류도 수정했다. 메인페이지 비교는 오류 화면 대신 복구한 코드에 기존 CSS와 통합 CSS를 각각 적용하여 수행했다.

## 유지한 규칙 및 검사의 한계

상태·반응형·문서 예시·공개 사이트 범위의 스타일은 역할에 따라 유지했다. 분산 0개는 모든 서로 다른 선택자 간 CSS 우선순위 관계가 제거되었다는 뜻이 아니다. site.css의 .public-site 범위 규칙 등은 여전히 존재한다.

!important 3개는 prefers-reduced-motion에서 애니메이션을 줄이는 용도로 유지했다.

check:styles는 같은 파일·같은 조건에서 동일 선택자가 다시 분산되면 실패하도록 강화했다. JSON 보고서는 node tools/audit-css.cjs --report로 갱신한다.
